# Проверка Filvless 0.4.0 preview

15 сентября 2026 года. Проверки новой версии:

- 92 модульных теста прошли; универсальный APK собран и подпись проверена.
- Обновление поверх 0.3.0 на Android 15 прошло успешно с сохранением подписки.
- Иконка пинга возле «Обновить» запускает проверку: в списке появляются задержки.
- Android vibrator_manager зарегистрировал два импульса Step=25ms: при включении
  и при выключении VPN. Физическая сила вибрации на телефоне не проверялась.
- Компактный список и усиленное свечение подключённого состояния осмотрены
  на реальном рендере Android-эмулятора.
- Новый логотип виден в меню приложений Android без обрезки знака.

Проверки базовых сценариев, выполненные также для 0.3.0:

- `:app:testPlaystoreDebugUnitTest`: 92 теста, 0 ошибок, 0 пропусков.
- `:app:assemblePlaystoreDebug`: успешная сборка универсального APK.
- `apksigner verify`: подпись корректна; `aapt dump badging`: Filvless во всех
  языках, package ru.filvless.vpn, versionCode 4000004, четыре архитектуры.
- Обновление установленного APK на Android 15 (API 35, x86_64): успешно.
- Подстановка скопированной ссылки в диалог: проверено совпадение поля.
- Загрузка ранее отклонённой подписки с HWID: получены реальные серверы.
  Отказ старого клиента подтверждён заголовком x-hwid-not-supported=true.
- Общий список без вкладок Default/import sub: проверен.
- Выбран сервер, принято системное разрешение VPN, создан tun0,
  CoreVpnService работает в foreground, отображаются статус и таймер.
- HTTP-запрос из эмулятора при работающем VPN получил 200.
- При прокрутке серверов положение таймера и статуса не меняется.
- После обновления сохранены подписка и настройки; срок подписки отображается.
- Остановка VPN удаляет tun0.

Новые тесты проверяют стабильность/формат HWID и безопасные значения заголовков.

## Практические пределы проверки

Изменение внешнего IP, утечки DNS, UDP, смена сети, физическая вибрация и длительная
работа в фоне на реальном телефоне отдельно не подтверждены. Проверка HTTP 200
не заменяет проверку всех маршрутов. Полный сценарий TalkBack не выполнялся.
APK подписан тестовым ключом и опубликован как предварительная версия.
