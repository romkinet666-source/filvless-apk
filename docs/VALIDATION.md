# Проверка Filvless 0.1 preview

## Автоматические проверки

Локальный результат 15 сентября 2026: сборка APK успешна, **84 теста пройдены,
0 ошибок, 0 пропусков**. Отдельный запуск трёх тестов Filvless также успешен.
Подпись APK проверена `apksigner` (v2). Все 12 требуемых нативных записей в
универсальном APK присутствуют. `aapt` подтвердил имя Filvless, package
`ru.filvless.vpn`, minSdk 24 и четыре архитектуры.

```text
:app:testPlaystoreDebugUnitTest --tests com.v2ray.ang.ui.main.FilvlessSubscriptionStateTest
:app:testPlaystoreDebugUnitTest
:app:compilePlaystoreDebugKotlin
:app:assemblePlaystoreDebug
```

Новые тесты: распознавание отказа провайдера, обычные/пустые названия серверов,
таймер при отсутствии отметки запуска, сбросе монотонных часов и нормальном ходе времени.

Проверка APK: идентификатор `ru.filvless.vpn`, имя Filvless,
подпись APK и наличие `libgojni.so`, `libhev-socks5-tunnel.so`, `libhevsockstun.so`
для arm64-v8a, armeabi-v7a, x86 и x86_64.

## Not run

На машине разработки не обнаружено подключённого Android-устройства или готового AVD.
Следующие проверки требуют устройства и остаются невыполненными:

- Установка, холодный запуск и визуальная проверка интерфейса.
- Пустой список, загрузка, ошибка провайдера, список реальных серверов.
- Импорт с открытой клавиатурой; достижимость поля и кнопки.
- Touch, keyboard, D-pad и TalkBack: порядок фокуса, подписи и активация.
- Выбор сервера и сохранение после закрытия/открытия приложения.
- Системное разрешение VPN; успешное подключение и ошибка подключения.
- Таймер после поворота, пересоздания Activity и повторного открытия клиента.
- Остановка, повторное подключение, смена сети, работа в фоне.
- Сквозная проверка IP, DNS и UDP на сервере владельца.

Ссылка владельца возвращает отказ устройства вместо рабочих узлов.
Этот результат не доказывает неработоспособность ссылки в уже настроенном Happ.
