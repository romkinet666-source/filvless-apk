# Проверка Filvless

## Проверка 0.6.6 preview

- После публикации выполнено настоящее обновление из GitHub: на эмулятор возвращён опубликованный 0.6.5, приложение само скачало 87056797 байт версии 0.6.6. При холодном запуске открылся системный установщик. После подтверждения установлен versionCode 4000013; update.apk и app-update.json удалены автоматически. Локальная фикстура APK в этом сценарии не использовалась.
- Русский диалог трёх режимов просмотрен на экране 360 dp; выбранный режим «Только Wi-Fi» сохранился после принудительного закрытия и повторного запуска.

- 118 JVM-тестов: 0 ошибок. Новые сценарии: конечные повторные попытки HTTP-проверки, отмена после остановки/потери сети, поздние события старой сети, повторное появление той же сети, сохранение JSON-балансировщиков и режим ручной загрузки.
- 10 обычных Android-тестов прошли. Проверка HTTP выполнена через настоящий Xray с тестовым freedom-outbound и локальным HTTP 204; после остановки ядра тест вернул недоступность. Проверена отмена очереди DownloadManager при выборе ручного режима, явное скачивание и сохранение уже скачанного файла при смене режима.
- Две дополнительные фикстуры пропускаются в обычном прогоне (установщик и переключение сетей). Сетевой сценарий отдельно выполнен с networkRecovery=true на Android 15: AVAILABLE → Wi-Fi выключен → RECOVERING → AVAILABLE через mobile → обе сети выключены → WAITING_NETWORK → Wi-Fi включён → RECOVERING → AVAILABLE → ручной STOPPED. Следующая смена сети не запустила VPN. Тест завершился за 19,237 с.
- Сетевая фикстура использует настоящий Android VPN-интерфейс и Xray с freedom-outbound, без пользовательской подписки и удалённого VPN-сервера. Проверка на физическом телефоне/у конкретного оператора остаётся отдельным этапом.
- Сборка универсального APK и Android Lint прошли: 0 ошибок, 339 предупреждений, 1 подсказка. APK подписан, applicationId ru.filvless.vpn, versionCode 4000013; четыре ABI. Проверка отсутствия текущего токена панели внутри APK пройдена.

## Проверка 0.6.5 preview

- 110 JVM-тестов прошли, включая ограничения URL репозитория, SHA-256 и размера пакета.
- 7 обычных Android-тестов прошли, включая сохранение нового пакета, удаление уже установленного и отказ от установки некорректного файла. Дополнительный тест подготовки установочного APK выполняется только с явным параметром; в обычном прогоне пропускается.
- На Android 15 отдельно пройден настоящий системный установщик: тестовая сборка с номером 0.6.4 и новым механизмом обновления получила локально подготовленный подписанный 0.6.5. Проверены разрешение источника, отмена с сохранением APK, повторная установка, versionCode 4000012 и удаление update.apk и app-update.json после MY_PACKAGE_REPLACED.
- Локальный пакет в первом сценарии зарегистрирован в DownloadManager тестовым кодом, который не входит в основной APK.
- После публикации отдельно проверена настоящая загрузка из GitHub: тестовая старая версия автоматически скачала APK размером 87025115 байт без браузера. При следующем возвращении из домашнего экрана открылся системный установщик. После подтверждения установлен versionCode 4000012; APK и app-update.json удалены автоматически.
- Android Lint: 0 ошибок, 338 предупреждений. Новые разрешения ограничены запросом системной установки; бесшумная установка не используется.

## Проверка 0.6.3 preview

- Итоговый главный экран визуально проверен на Android 15. Отступ таймер/статус 16 dp.
- Проверка обновлений вызывается при старте и onResume, повторные запросы ограничены 30 секундами; ручная проверка не ограничена этим интервалом.

## Проверка 0.6.0 preview

- 100 Android/JVM модульных тестов прошли. Проверены допустимый домен и схема
  ссылки, запрет URL с чужим хостом, userinfo, нестандартным портом, query и
  закодированным путём, а также разбор и уникальность идентификаторов устройств.
- 17 тестов Python API прошли локально и на сервере. Проверены неверная подписка,
  несовпадение владельца, подмена userId, чужое устройство, повторное удаление,
  лимит запросов, повреждённый JSON, отсутствие секретных полей в ответе и выбор
  отдельного токена устройств, если он задан. Рабочая конфигурация использует один токен.
- Два UI-теста на Android 15 прошли: отображение текущего устройства,
  обязательное подтверждение/отмена удаления и сообщение о недостающих правах
  панели с повторной загрузкой. Визуальные тесты используют вымышленные устройства.
- API установлен отдельной systemd-службой за Caddy; токен имеет права 600/root,
  Gunicorn слушает только 127.0.0.1:8765. HTTPS проверен обычным доверенным TLS-клиентом.
  `/health` возвращает 200; запрос устройств без авторизации возвращает 401.
  Все ранее работающие сервисы мониторинга остались активны.
- После установки нового токена чтение пользователя и его устройств возвращает
  HTTP 200. Проверка через публичный gateway также вернула HTTP 200 и реальный
  список устройств. Прежнее ограничение 403 устранено на сервере без изменения APK.
- Реальное удаление в панели намеренно не выполнялось: обработка удаления
  проверена на тестовых данных. Права токена через административный обход не менялись.
- При замене токена обновляется серверный environment и перезапускается только
  filvless-api. APK 0.6.0 остаётся прежним.

## Проверка 0.5.0 preview

- 97 модульных тестов прошли без ошибок. Новые проверки: сравнение preview/rc/stable
  версий, выбор только универсального APK из своего репозитория, нормализация
  доменов и конфликты правил, применение правил к готовому JSON без потери
  правил провайдера, отказ при отсутствии VPN-выхода для явного VPN-правила.
- Android-интеграционный тест на API 35 прошёл: реальный CoroutineWorker
  импортирует конфигурацию с локального HTTP-сервера; HTTP 500 возвращает Retry
  и сохраняет прежние серверы/lastUpdated; выключенная функция не делает запросов.
- WorkManager зарегистрировал две периодические задачи с интервалом 21600000 мс:
  обновление подписки и проверку новых версий. Ожидание полного шестичасового
  интервала и доставка уведомления о будущей версии отдельно не проверялись.
- На Android 15 проверены переключатель автообновления и редактор сайтов;
  правило example.com сохранено, VPN с пользовательским правилом создал tun0.
  Проверка разных внешних IP для маршрутов VPN/напрямую отдельно не выполнена.
- Управление устройствами не реализовано: требуется пользовательский API сервиса.

## Практические пределы проверки

Изменение внешнего IP, утечки DNS, UDP, смена сети, физическая вибрация и длительная
работа в фоне на реальном телефоне отдельно не подтверждены. Проверка HTTP 200
не заменяет проверку всех маршрутов. Полный сценарий TalkBack не выполнялся.
APK подписан тестовым ключом и опубликован как предварительная версия.
