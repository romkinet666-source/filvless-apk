# Filvless для Android

Тестовый Android-клиент VPN на основе v2rayNG и Xray с интерфейсом Filvless.

**Статус: 0.1 preview.** APK собирается, но полноценная проверка на Android-устройстве
и сквозное VPN-подключение к серверам владельца пока не выполнены.

## Что реализовано

- Отдельное приложение `ru.filvless.vpn` с названием и иконкой Filvless.
- Почти чёрный фон, глубокий фиолетовый градиент и светлые акценты.
- Импорт ссылки подписки или конфигурации с главного экрана.
- Загрузка и обновление серверов, выбор сервера, запуск и остановка VPN.
- Таймер от монотонного времени запуска ядра в службе, а не открытия экрана.
- Статус подключения из событий VPN-службы.
- Карточки настроек: подписки, маршрутизация, приложения, диагностика.
- Обнаружение служебного ответа «Данное устройство не поддерживается».

Подробные экраны настроек пока унаследованы от v2rayNG. В первой версии нет
оплаты, входа в аккаунт, интеграции кнопки бота и полного повторения всех настроек
VPNUS. Автозапуск и другие расширенные параметры доступны в унаследованных настройках;
отдельные переключатели вибрации и визуальных эффектов пока не реализованы.

## Установка

В разделе **Releases** скачайте единственный **универсальный APK Filvless**.
Он содержит все четыре поддерживаемые архитектуры: выбирать тип процессора не нужно.
В **Actions → Build Filvless APK** новые тестовые сборки также публикуются
одним универсальным APK в артефакте **Filvless-preview-APK**.

Это debug-сборка для тестирования, не релиз для массового распространения.
Локальные APK и APK разных запусков CI могут иметь разные тестовые подписи.
Перед публичным выпуском нужен постоянный ключ подписи; его нельзя коммитить.

После установки: **Добавить → вставить ссылку → выбрать сервер → подключить**.
Android запросит разрешение на VPN-соединение. Каждый пользователь добавляет
свою подписку; в приложении нет общей встроенной подписки владельца.

## Ограничение проверенной подписки

При разработке сервер подписки возвращал служебные VLESS-записи вместо рабочих
серверов, в том числе с обозначением клиента Happ. Причина ограничения не установлена.
Одной смены User-Agent оказалось недостаточно. Требуется проверить правила выдачи
подписки и привязку устройства у провайдера. Личная ссылка и ключи в репозитории отсутствуют.

## Сборка в Windows

Нужны Git, JDK 21, Android SDK (`platforms;android-37.0`, `build-tools;36.0.0`),
NDK `30.0.16138531`. Gradle 9.5.1 скачивается wrapper-скриптом.

```powershell
git clone --recurse-submodules https://github.com/romkinet666-source/filvless-apk.git
cd filvless-apk
./scripts/build-windows.ps1 -SdkPath 'C:/path/to/Android/Sdk'
```

Скрипт загружает фиксированную версию Xray, проверяет SHA-256, собирает HEV,
запускает модульные тесты и собирает один APK со всеми объявленными архитектурами.
Результат: `V2rayNG/app/build/outputs/apk/playstore/debug/`.
