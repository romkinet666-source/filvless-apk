# Filvless для Android

Тестовый Android-клиент VPN на основе v2rayNG и Xray с интерфейсом Filvless.

**Статус: 0.6.8 preview.** Проверены установка на Android 15, загрузка подписки
с HWID и запуск VPN-туннеля. Версия предназначена для тестирования.

## Новое в 0.6.8

- Настройки → «VPN в шторке»: системное добавление плитки на Android 13+, инструкция для старых версий. Плитка Filvless включает/выключает VPN; при отсутствии сервера или разрешения открывает приложение. Удержание открывает Filvless.
- Ожидающее подключение можно отменить. По тайм-ауту отправляется остановка; до успешной проверки туннеля интерфейс показывает проверку, а не подтверждённое подключение.
- Неудачное обновление подписки помечается отдельно от времени последнего успеха. Предыдущий список сохраняется при пустом ответе, ошибке и служебном профиле отказа провайдера. Статус и время видны в настройках.
- «Мои устройства»: локальные названия через значок карандаша. Пустое название возвращает исходную модель. Названия сохраняются только на этом телефоне и не отправляются на сервер.
- «Работа в фоне» показывает доступные Android сведения об ограничениях и энергосбережении, открывает системные настройки. Ограничения производителей могут быть доступны не полностью.
- Загрузку обновления можно отменить; фоновая задача не скачивает отменённую версию заново без явного запуска. Добавлены проверка свободного места, отдельные сообщения об ошибках сети/места/проверки пакета и однократная карточка «Что нового» после установки.

## Новое в 0.6.7

- Настройки → «Не работает интернет?»: проверка сети, ответа подписки, TCP-доступности подходящего сервера и HTTP-доступа через работающий туннель. Есть повторная проверка, поддержка и копирование отчёта без ссылок подписки, ключей и идентификаторов устройства.
- Напоминание об окончании подписки: один раз в последние три дня, по сроку из последнего обновления подписки. Настройку можно выключить; уведомление открывает @filvless_bot. Android может откладывать фоновый запуск, это не точный будильник.
- Обновления показывают размер APK, краткий список изменений и ожидание Wi-Fi. «Напомнить завтра» откладывает предложение конкретной версии на 24 часа. Перед системной установкой готового пакета показывается экран с описанием и кнопками установки/отсрочки.
- Пинг окрашен по задержке, результаты меняются плавно без изменения высоты строки. Долгое нажатие открывает полное название сервера. После успешной проверки соединения — короткий фиолетовый импульс, если визуальные эффекты включены.
- Автоматический выбор/смена сервера, избранное и импорт одной кнопкой из бота в эту версию не входят.

## Новое в 0.6.6

- После подключения клиент проверяет HTTP-доступ через работающий Xray. Состояния: проверка, подтверждённый доступ, ожидание сети и неподтверждённая связь. Проверка выполняет до трёх попыток с двумя контрольными адресами, не продолжаясь бесконечно.
- При переходе Wi-Fi ↔ мобильная сеть и возврате сети после обрыва клиент восстанавливает ядро, сохраняя VPN-интерфейс, затем повторяет проверку. Поздняя потеря старой сети не сбрасывает новую. Ручная остановка отменяет восстановление.
- Настройки → Обновление приложения → Фоновая загрузка: только Wi-Fi, любая сеть или вручную. Проверка новой версии и уведомления остаются во всех режимах. При обновлении сохраняется прежнее поведение «Любая сеть», роуминг отключён.
- Смена режима отменяет и при необходимости заново ставит в очередь незавершённый APK. Уже скачанный пакет сохраняется для установки.
- Служебная проверка добавляет только локальный вход в конфигурацию текущего запуска; сохранённые JSON-подписки, серверы и балансировщики не переписываются. Проверка следует маршрутизации текущей конфигурации и не является тестом каждого сайта или проверкой утечек.

## Новое в 0.6.5

- Новые APK скачиваются внутри приложения через Android DownloadManager: загрузка продолжается в фоне и переживает обрывы связи.
- При следующем открытии готовый пакет проверяется, затем открывается системный установщик. Если разрешение на установку из Filvless не выдано, приложение объясняет, как его включить.
- Экран обновления показывает прогресс, готовность и повторную попытку. Браузер для скачивания больше не требуется.
- До установки проверяются SHA-256 и размер из GitHub, имя пакета, версия и совпадение сертификатов подписи.
- После успешного обновления пакет и запись DownloadManager удаляются через MY_PACKAGE_REPLACED; очистка повторяется при старте на случай пропущенного события.
- Отмена установки сохраняет APK для повторной попытки. Автоматический запуск установщика предлагается один раз для пакета, затем доступен вручную.
- Установка требует системного подтверждения пользователя. Автозагрузка разрешена по Wi-Fi и мобильной сети, в роуминге отключена.

## Новое в 0.6.4

- Проверки пинга переиспользуют ограниченный пул IO-потоков; повторный запуск одной проверки не дублирует результаты, отмененная проверка не стартует заново.
- Фильтрация списка серверов больше не повторяется на каждом тике таймера.
- Настройки автообновления подписок записываются только при изменении.
- Закрытие экрана устройств отменяет его HTTP-запрос и корректно закрывает поздний ответ.
- Root-команды читают вывод параллельно с ожиданием: тайм-аут действует при зависании чтения, сохраняемый вывод ограничен 64 Ки символов.

## Новое в 0.6.3

- Увеличен отступ между таймером и статусом подключения: 16 dp.
- Автоматическая проверка версии при возвращении на главный экран; защита от повторных запросов чаще одного раза в 30 секунд. Ручная проверка доступна сразу.
- Новая версия показывается в диалоге со скачиванием. После закрытия диалога баннер остается на экране.
- Удалены неиспользуемые диалоги старого управления подпиской и скрытой маршрутизации.
- Измерение TCP использует монотонные часы, успешные ответы быстрее миллисекунды отображаются как 1 мс.

## Новое в 0.6.2

- Вращающийся значок проверки, пока измеряется задержка серверов.
- Кнопка списка запускает быструю TCP-проверку: до 16 профилей одновременно, тайм-аут соединения 1 секунда. Разрешение DNS может занять дополнительное время.
- JSON-профили поддерживаются без запуска Xray: измеряется первый подходящий TCP-сервер профиля. Это доступность TCP-порта, а не проверка авторизации, маршрутизации или всей группы балансировки. UDP-профили этой проверкой не измеряются.
- Компактнее название FILVLESS и таймер; статус подключения в фиолетовой рамке.

## Что реализовано

- Отдельное приложение `ru.filvless.vpn` с названием и иконкой Filvless.
- Почти чёрный фон, глубокий фиолетовый градиент и светлые акценты.
- Импорт ссылки подписки или конфигурации с главного экрана.
- Загрузка и обновление серверов, выбор сервера, запуск и остановка VPN.
- Таймер от монотонного времени запуска ядра в службе, а не открытия экрана.
- Статус подключения из событий VPN-службы.
- Новый экран настроек по референсам: подписка, оформление, функции и информация. Раздела «Туннель» нет.
- Обнаружение служебного ответа «Данное устройство не поддерживается».

Настройки включают выбор системного, русского или английского языка, подключение
при запуске, виброотклик и визуальные эффекты. Значения сохраняются между запусками.
Срок подписки отображается, если сервер передаёт его в Subscription-Userinfo.

## Установка

В разделе **Releases** скачайте единственный **универсальный APK Filvless**.
Он содержит все четыре поддерживаемые архитектуры: выбирать тип процессора не нужно.
В **Actions → Build Filvless APK** новые тестовые сборки также публикуются
одним универсальным APK в артефакте **Filvless-preview-APK**.

Это debug-сборка для тестирования, не релиз для массового распространения.
Локальные APK и APK разных запусков CI могут иметь разные тестовые подписи.
Перед публичным выпуском нужен постоянный ключ подписи; его нельзя коммитить.

После установки: **Добавить → вставить ссылку → выбрать сервер → подключить**.
Android запросит разрешение на VPN-соединение. Каждый пользователь добавляет
свою подписку; в приложении нет общей встроенной подписки владельца.

## Подписки и идентификатор устройства

С версии 0.3.0 приложение отправляет стабильный идентификатор устройства (HWID)
при загрузке подписки. Это устраняет отказ `x-hwid-not-supported` у провайдеров,
которым нужен этот заголовок. Ограничения количества устройств остаются в силе.
После обновления с 0.1/0.2 нажмите «Обновить», чтобы перезагрузить серверы.
Личные ссылки и ключи не встроены в приложение.

Главный экран показывает общий список серверов без вкладок Default / import sub.
Таймер, статус и кнопка компактны и закреплены над прокручиваемым списком.
При нажатии «Добавить» поле заполняется из буфера обмена; импорт подтверждается
отдельной кнопкой. Пустой буфер оставляет поле пустым.

## Сборка в Windows

Нужны Git, JDK 21, Android SDK (`platforms;android-37.0`, `build-tools;36.0.0`),
NDK `30.0.16138531`. Gradle 9.5.1 скачивается wrapper-скриптом.

```powershell
git clone --recurse-submodules https://github.com/romkinet666-source/filvless-apk.git
cd filvless-apk
./scripts/build-windows.ps1 -SdkPath 'C:/path/to/Android/Sdk'
```

Скрипт загружает фиксированную версию Xray, проверяет SHA-256, собирает HEV,
запускает модульные тесты и собирает один APK со всеми объявленными архитектурами.
Результат: `V2rayNG/app/build/outputs/apk/playstore/debug/`.
