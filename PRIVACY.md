# Данные в тестовой версии Filvless

Это техническое описание версии 0.5, а не утверждение о практике VPN-провайдера.

- Ссылки подписок и параметры серверов хранятся в закрытом каталоге приложения.
- Android backup отключён. Копирование конфигураций пользователем остаётся возможным.
- При обновлении приложение обращается к адресу подписки пользователя.
- При включённом автообновлении эти обращения выполняются также в фоне, примерно
  раз в 6 часов при наличии интернета.
- Проверка новых версий обращается к публичному API GitHub репозитория
  romkinet666-source/filvless-apk. Ссылка подписки и HWID в этот запрос не добавляются.
  Скачивание APK открывается по действию пользователя.
- Пользовательские списки доменов маршрутизации сохраняются локально; правила
  «Напрямую» отправляют соответствующий трафик без VPN. Выбор приложений также
  хранится локально и используется Android VPN-службой.
- Для учёта устройств исходному серверу подписки отправляются HWID (SHA-256 от
  идентификатора Android, ограниченного приложением), версия Android и модель.
  Исходный Android ID не передаётся. При отсутствии Android ID используется
  сохранённый случайный идентификатор. Сброс лимитов провайдера не производится.
- Буфер обмена читается при нажатии «Добавить» для заполнения поля; содержимое
  отправляется на импорт только после подтверждения пользователя.
- При подключении трафик передаётся выбранному VPN-серверу; обработка данных
  на этом сервере зависит от его владельца.
- Проверка доступности обращается к адресам, заданным в настройках клиента.
- Диагностические журналы исходной основы могут содержать сведения о конфигурации.
  Перед передачей журналов проверяйте и удаляйте конфиденциальные данные.
- В репозитории нет рабочих подписок, пользовательских ключей или ключа
  подписи производственного приложения.

Перед публичным выпуском оператор сервиса должен дополнить документ своими
контактами и описанием обработки данных на стороне серверов.
