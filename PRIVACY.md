# Данные в тестовой версии Filvless

Это техническое описание версии 0.6, а не утверждение о практике VPN-провайдера.

- Ссылки подписок и параметры серверов хранятся в закрытом каталоге приложения.
- Android backup отключён. Копирование конфигураций пользователем остаётся возможным.
- При обновлении приложение обращается к адресу подписки пользователя.
- При включённом автообновлении эти обращения выполняются также в фоне, примерно
  раз в 6 часов при наличии интернета.
- Проверка новых версий обращается к публичному API GitHub репозитория
  romkinet666-source/filvless-apk. Ссылка подписки и HWID в этот запрос не добавляются.
  Скачивание APK выполняется Android DownloadManager в соответствии с режимом
  «Только Wi-Fi», «Любая сеть» или «Вручную». При обновлении с предыдущей версии
  сохраняется «Любая сеть». В роуминге скачивание отключено. Готовый APK хранится
  в каталоге приложения до успешной установки и затем удаляется.
- Пользовательские списки доменов маршрутизации сохраняются локально; правила
  «Напрямую» отправляют соответствующий трафик без VPN. Выбор приложений также
  хранится локально и используется Android VPN-службой.
- При открытии «Мои устройства» приложение обращается к apkapi.flynode.ru.
  В заголовке Authorization передаётся секретный идентификатор из ссылки подписки,
  а в X-Device-Id — HWID текущего приложения для отметки «Это устройство».
  Поддерживаются только ссылки HTTPS с домена sub.prostobotyg.ru.
- Сервер получает из панели владельца подписки и список его устройств, возвращает
  модели, платформы, версии ОС, даты запросов и непрозрачные идентификаторы записей.
  Ответы не кэшируются; база устройств на сервере API не создаётся. Заголовки
  авторизации и тела запросов не записываются в журнал доступа.
- Владение ссылкой подписки даёт доступ к управлению её устройствами. Отдельная
  авторизация через Telegram не реализована. Удаление записи устройства требует
  подтверждения и не отзывает ранее загруженные параметры VPN.
- Для учёта устройств исходному серверу подписки отправляются HWID (SHA-256 от
  идентификатора Android, ограниченного приложением), версия Android и модель.
  Исходный Android ID не передаётся. При отсутствии Android ID используется
  сохранённый случайный идентификатор. Сброс лимитов провайдера не производится.
- Буфер обмена читается при нажатии «Добавить» для заполнения поля; содержимое
  отправляется на импорт только после подтверждения пользователя.
- При подключении трафик передаётся выбранному VPN-серверу; обработка данных
  на этом сервере зависит от его владельца.
- Проверка доступности обращается к адресам, заданным в настройках клиента.
  После подключения и восстановления сети выполняются короткие HTTP-проверки
  через локальный вход работающего Xray с правилами текущей конфигурации.
  Используются основной и резервный контрольные адреса; максимум три попытки
  на подключение/восстановление. Данные подписки в эти запросы не добавляются.
- Диагностические журналы исходной основы могут содержать сведения о конфигурации.
  Перед передачей журналов проверяйте и удаляйте конфиденциальные данные.
- В репозитории нет рабочих подписок, пользовательских ключей или ключа
  подписи производственного приложения.

Перед публичным выпуском оператор сервиса должен дополнить документ своими
контактами и описанием обработки данных на стороне серверов.

Обновления приложения: Filvless автоматически скачивает новые универсальные APK из своего GitHub Releases через системный DownloadManager. GitHub получает обычные сетевые данные запроса. Пакет хранится в каталоге приложения, проверяется перед установкой и удаляется после успешного обновления. Установка требует подтверждения Android; при отмене пакет сохраняется для повторной попытки.

Диагностика «Не работает интернет?» запускается пользователем. Она обращается к исходному адресу подписки с теми же заголовками устройства, что импорт, проверяет подходящий адрес сервера и выполняет контрольный запрос через работающий Xray. Серверы и конфигурации не меняются. Копируемый отчёт содержит только версии приложения/Android и фиксированные коды результатов; отправка в поддержку не выполняется автоматически.

Напоминание об окончании использует сохранённый срок подписки. Уведомление содержит дату, открывает бота покупки и не показывает ссылку подписки или ключи. Отметка о показе и отсрочка обновления приложения хранятся локально.

Названия устройств, заданные пользователем, сохраняются локально и привязаны к подписке и записи устройства. Они не отправляются в панель. Экран «Работа в фоне» читает системные ограничения и открывает настройки только по нажатию пользователя.
